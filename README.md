# 🐾 Добрый хвост

Веб-приложение ветеринарной клиники, разработанное на Django.

## О проекте

Проект создан в учебных целях и представляет собой сайт ветеринарной клиники с возможностью просмотра информации о врачах и записи на приём.

## Основной функционал

- Главная страница клиники
- Просмотр списка ветеринаров
- Поиск врачей
- Онлайн-запись на приём
- Django Admin для управления данными
- Адаптивный интерфейс
- Клиентская валидация формы

## Технологии

- Python
- Django
- SQLite
- HTML5
- CSS3
- JavaScript
- Git

## Структура проекта

- `clinic/` — настройки проекта
- `vetclinic/` — приложение
- `templates/` — HTML-шаблоны
- `static/` — CSS, JavaScript и изображения

## Статус проекта

Учебный проект. Продолжаю улучшать функциональность и изучать новые технологии.
